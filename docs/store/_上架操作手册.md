## 三、产品声明（🔴 最容易出错，逐项核对）

| 勾选项 | 正确做法 | 原因 |
|---|---|---|
| 此产品允许用户购买，但不使用 Microsoft Store 商务系统 | ✅ **必须勾** | 激活码在自有渠道成交（微信/支付宝），不勾=虚假声明，拒审或下架 |
| 客户可用 Windows 10/11 功能录制和广播剪辑 | ❌ 取消 | 只有「游戏」类别支持广播录制，我们是生产率 |
| 客户可将产品装到备用驱动器或可移动存储 | ⚠ 建议取消 | MSIX 可装备用盘但装不进 U 盘，过度承诺 |
| Windows 可将数据包含在 OneDrive 自动备份 | 保留 | 低风险 |
| 产品已通过辅助功能准则测试 | 保持不勾 | 未逐项测不虚报；不勾不影响上架 |
| 支持笔墨输入 | 不勾 | 不支持 |
| 集成生成式 AI 功能 | 不勾 | 代码里无任何 LLM/API 调用 |

## 四、属性与支持信息

- [ ] 系统要求：键盘 ☑ 鼠标 ☑，其余（触摸/相机/NFC/蓝牙/麦克风/Xbox/WMR）全不勾；内存 4 GB；DirectX 未指定
- [ ] 显示模式（Mixed Reality）：电脑 ☐ HoloLens ☐ **都不勾**（勾了会逼填头显硬件并弹红字）
- [ ] 支持信息：网站 `https://reedskill.com/`；支持联系信息照文案的中文段落
- [ ] 电话 / 地址 / 邮编 / 市县 / 省 / 国家：**全部留空**（会公开显示，暴露真实所在地）；若强制要求国家填主体注册地

## 五、上传程序包

- [ ] 从 GitHub Release v1.3.170 / v1.1.66 下载 `MDF-Stu.msix` / `MDF-Advisor.msix`
- [ ] Partner Center 新建提交 → 上传对应 .msix
- [ ] 系统解析后核对：Package name / Publisher / Version(1.3.170.0 / 1.1.66.0) / 功能 runFullTrust
- [ ] **.msix 未签名是正常的** —— 微软收件时签名，不要本地自签
- [ ] 提交备注里写明：购买在 reedskill.com 通过微信/支付宝完成，应用内仅输入激活码、不集成 Store 商务系统

## 六、提交后

- [ ] 提交认证，等微软审核（海外版几天内通过）
- [ ] 若收到 IARC Live Rating Notice：纯通知，无需处理，存好 Global Rating ID
- [ ] 若安装报 `0x80073CFB`：= ERROR_PACKAGE_ALREADY_EXISTS，本机有旧自签测试包，用 `Remove-AppxPackage` 卸载即可
